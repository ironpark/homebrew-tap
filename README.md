# Homebrew tap

Homebrew formulas for ironpark's tools.

```sh
brew install ironpark/tap/ggui
```

| Formula | What it is |
| --- | --- |
| [ggui](https://github.com/ironpark/ggui/blob/main/docs/cli.md) | Create, run, check and bundle [ggui](https://github.com/ironpark/ggui) applications |

The formulas are written by each project's release workflow; edits made
here by hand are overwritten by the next release.
